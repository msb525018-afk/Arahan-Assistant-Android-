Arahan Assistant
================
نسخه قابل دانلود و اجرای مستقل برنامه.

اجرای سریع نسخه آماده:
1) وارد پوشه dist شوید.
2) یکی از روش‌های زیر را اجرا کنید:
   - Python: python -m http.server 8080
   - Node: npx serve .
3) مرورگر را روی http://localhost:8080 باز کنید.

نسخه تولیدشده یک برنامه وب مستقل و قابل اجراست. داده‌های فضای کاری در localStorage مرورگر ذخیره می‌شوند. برای اتصال موتورهای واقعی پردازش متن، OCR، پژوهش وب و تولید تصویر، پیکربندی موتور مربوط در مرکز موتورهای آراهان انجام می‌شود؛ برنامه نتیجه یا منبع ساختگی نمایش نمی‌دهد.

ساخت مجدد از کد:
npm install
npm run build
